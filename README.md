# java-calculator-precourse

구현할 기능 목록
1. 문자열 입력 받기 -> 메인에서 바로 받음
2. 구분자 기준으로 숫 분리 후 합하기 -> 완료
    2-2. 7:53 10/14 한글이 깨짐
3. 예외처리 진행  -> 예외처리 완료 10/15 11:40
4. 출력 완료
5. 기타 추가
   5-2. 양수 조건이 있었네
6. 커스텀 구분자
    6-2. 사이에 넣는거였어
    6-3. //;\n1;2;3 이면 , : ; 이렇게 추가하는 걸로해야겠다
    6-4. 추가로 넣어보자 만약 테스트케이스 통과안되면 하나만하는걸로
7. 리드미 정리하기 컨벤션 참고
8. 자바 코드 컨벤션 자바 스타일 가이드 원칙
10/15 예외처리 공부함
9. 클래스를 나누는게 좋을까?
